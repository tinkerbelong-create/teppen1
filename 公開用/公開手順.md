# GitHub Pages で公開する手順

`公開用` フォルダの中身をアップロードするだけで、スマホから遊べるURLが手に入ります。
**プログラムの知識もアプリのインストールも要りません。** ぜんぶブラウザだけで完結します。

フォルダの中身：

- `index.html` … テストプレイ（ゲーム本体）
- `cards.html` … 全カード一覧

---

## 手順1　GitHubのアカウントを作る（持っていれば飛ばす）

1. https://github.com/signup を開く
2. メールアドレス・パスワード・ユーザー名を入れて登録
3. 届いたメールの認証コードを入力

**ユーザー名はURLの一部になります。** 短くて分かりやすいものにしてください。
（例：ユーザー名が `arai-asobi` なら、URLは `arai-asobi.github.io/...` になります）

---

## 手順2　置き場所（リポジトリ）を作る

1. https://github.com/new を開く
2. **Repository name** に `teppen` と入力（好きな名前でOK。半角英数字）
3. **Public** を選ぶ　← ここ重要
   - Private だと無料では公開できません
4. **Add a README file** に**チェックを入れる**
5. 緑の **Create repository** ボタンを押す

> **Public にすると誰でも見られる状態になります。** URLを知らない人にはまず見つかりませんが、完全な非公開ではありません。イナズマイレブンの画像を使っているので、URLを広く配ったり検索に載せたりはしないほうが安全です。身内のテストプレイ用に留めてください。

---

## 手順3　ファイルをアップロードする

1. できたリポジトリのページで **Add file** → **Upload files** を選ぶ
2. `公開用` フォルダの `index.html` と `cards.html` を、**2つまとめて枠の中にドラッグ＆ドロップ**
3. アップロードのバーが最後まで進むのを待つ（1ファイル2MBなので少しかかります）
4. 下の緑のボタン **Commit changes** を押す

---

## 手順4　公開をオンにする

1. リポジトリの上のほうにある **Settings**（歯車）を押す
2. 左のメニューから **Pages** を選ぶ
3. **Source** が `Deploy from a branch` になっているのを確認
4. **Branch** のところで `main` を選び、右の folder は `/ (root)` のまま
5. **Save** を押す

---

## 手順5　URLにアクセスする

**1〜3分待ってから**、Settings → Pages のページを再読み込みしてください。
上のほうに緑のチェックと一緒にURLが出ます。

```
https://（あなたのユーザー名）.github.io/teppen/
```

- ゲーム　→ `https://…github.io/teppen/`
- カード一覧　→ `https://…github.io/teppen/cards.html`

**すぐに出ない場合**：数分待ってもう一度リロードしてください。初回だけ時間がかかります。

---

## 手順6　スマホのホーム画面に置く

**iPhone（Safari）**

1. URLを開く
2. 下の共有ボタン（□に↑）を押す
3. 「ホーム画面に追加」を選ぶ

**Android（Chrome）**

1. URLを開く
2. 右上の「⋮」を押す
3. 「ホーム画面に追加」を選ぶ

アプリのように1タップで開けるようになります。

---

## 直したものを反映するとき

新しい `index.html` ができたら：

1. リポジトリのページで **Add file** → **Upload files**
2. 同じ名前のファイルをドラッグ＆ドロップ（上書きされます）
3. **Commit changes**

**1〜2分で反映されます。** 反映されないときはスマホのブラウザで強制リロードしてください。

---

## つまずきやすいところ

| 症状 | 原因と対処 |
|---|---|
| 404 が出る | まだ公開処理が終わっていない。3分ほど待って再読み込み |
| 404 のまま変わらない | リポジトリが Private になっている。Settings → General の一番下から Public に変更 |
| 画像が出ない | アップロードが途中で切れている。ファイルサイズが2MBあるか確認して上げ直す |
| 変更が反映されない | ブラウザのキャッシュ。URLの末尾に `?2` などを付けて開くと確実 |
| Pages のメニューがない | リポジトリが Private。Public にすると出てきます |
