# 効果音の差し替え方

いまの音は、**音のファイルを使わずに、ブラウザがその場で作って鳴らしています**（A案）。
気に入らない音、もっと本物らしくしたい音だけを、あとから**1つずつ**差し替えられます（B案）。
全部いっぺんに用意する必要はありません。ゴールの音だけ、キャッチの音だけ、でも大丈夫です。

---

## 手順（3つだけ）

### 1. 音のファイルを用意する

`.mp3` か `.wav` か `.ogg`。
**1〜2秒くらいの短いもの**を選んでください（長いと次の音とぶつかります）。

### 2. `音/` フォルダに入れる

`teppen/` の中に `音` という名前のフォルダを作って、そこに入れます。

```
teppen/
  音/
    goal.mp3
    stop.mp3
```

ファイル名は英数字にしてください（日本語でも動きますが、迷ったら英数字が安全です）。

### 3. `js/config.js` に1行書く

`js/config.js` の中の `sound:` の中にある `files: {}` を、こう書き換えます。

```js
    sound: {
      on: true,
      volume: 0.6,
      files: {
        goal: '音/goal.mp3',
        stop: '音/stop.mp3'
      }
    },
```

これだけです。**書いた音だけが差し替わり、書いていない音は今までどおり**鳴ります。
最後の行にはカンマ（,）を付けません。ここを間違えるとゲームが開かなくなるので、
そのときは書き足した部分を消せば元に戻ります。

## 音の名前の一覧

| 名前 | いつ鳴るか |
|---|---|
| `tap` | カードやボタンをさわった |
| `press` | ホームのボタン・キックオフを押した |
| `card` | カードを場に出した |
| `draw` | 山札から引いた |
| `turn` | 誰かの番になった |
| `ball` | ボールが人から人へ動いた |
| `dice` | サイコロが転がる |
| `diceOk` | サイコロ成功 |
| `diceNg` | サイコロ失敗 |
| `cutin` | 必殺技のカットイン |
| `goal` | ゴールが決まった |
| `stop` | キャッチ成功（とめた！） |
| `breakthrough` | ドリブル成功（ぬけた！） |
| `fail` | 反応できない・失敗した |
| `coin` | イナズマコインをもらった |
| `spend` | イナズマコインを払った |
| `steal` | 伏せ札をうばう・引き抜き |
| `takeover` | 手番を飛ばして自分の番になった |
| `win` | 勝った |
| `lose` | 負けた・引き分け |

**まず差し替えるならこの4つ**が効きます：`goal` / `stop` / `cutin` / `coin`。
この4つが「気持ちいい音」になるだけで、ゲーム全体の手ざわりが変わります。

## 音を探せる場所（日本語・無料）

いずれも定番のフリー効果音サイトです。
**使う前に、それぞれのサイトの利用規約（利用条件のページ）を必ず読んでください。**
配布のしかた（クレジット表記が要るか、ゲームに使ってよいか）はサイトごとに違います。

| サイト | URL | 向いているもの |
|---|---|---|
| 効果音ラボ | https://soundeffect-lab.info/ | 種類が多い。まずここ。ボタン・スポーツ・演出音 |
| 魔王魂 | https://maou.audio/ | ゲーム向けの効果音とBGM。決定音・成功音が強い |
| OtoLogic | https://otologic.jp/ | UI音・カード音がきれい。落ち着いた質感 |
| ポケットサウンド | https://pocket-se.info/ | 短い演出音が豊富 |

探すときのことば：
- `goal` → 「歓声」「ホイッスル」「ファンファーレ」
- `stop` → 「キャッチ」「衝撃」「インパクト」
- `cutin` → 「シュイーン」「登場」「必殺技」
- `coin` → 「コイン」「獲得」「アイテム取得」
- `card` → 「カードをめくる」「紙」

## 音を切る／音量を変える

遊ぶ人は、**ホーム画面の右下「音 オン／オフ」**か、
**設定画面の「音」**で切り替えられます。音量つまみもそこにあります。
この設定は端末ごとに覚えるので、一度切れば次からも切れたままです。

---

## うまく鳴らないとき

- **音が1つも鳴らない** … 画面を一度どこかタップしてください。ブラウザは「利用者が触るまで音を出さない」決まりになっています
- **差し替えた音だけ鳴らない** … ファイル名の大文字小文字が合っているか、`音/` フォルダの中にあるかを確認してください
- **音が重なってうるさい** … その音のファイルを、もっと短いものに替えてください
