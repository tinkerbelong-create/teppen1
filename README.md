# テッペンとリーヨ！ ── テストプレイ環境

紙のカードゲーム「テッペンとリーヨ！」を、画面の上で試すための道具です。
最終的に作るのは紙のゲームです。これはその**調整用の道具**です。

- **遊ぶ：** https://tinkerbelong-create.github.io/teppen1/
- **あそびかた（遊ぶ人向けルールブック）：** https://tinkerbelong-create.github.io/teppen1/あそびかた.html

> **いまはPC専用です。** 横長の大きい画面で見てください。スマホ対応はこのあと作ります。

---

## 何ができるか

- **1人でCPUと対戦**（2〜4人。CPUは1〜3体）
- **CPU同士を高速で回して統計を取る**（バランス調整用）
- **数値を画面から変える**：人数／収録キャラ（18人・21人・24人）／初期手札／勝利点／必殺カードとキャラカードの複製数／イナズマコインの増えかた

### いまの標準設定（CPU一括対戦で決めた値）

| | |
|---|---|
| キャラクター | 18種類（＋円堂守4種） |
| 必殺カード | 31種類 × 2枚 |
| キャラカード | 18種類 × 3枚 |
| **山札** | **117枚**（ボールカード1枚を含む） |
| 初期手札 | 14枚 |
| イナズマコイン | **カードではなくトークン。開始5個、上限12個** |

3人戦300試合で、規定点での決着93%、1試合48手、シュートの54%が連携技。

## 画面の見かた

上から順に5段です。**横スクロールも見切れもありません。** カードが増えたら自動で小さくなります。

| 段 | 中身 |
|---|---|
| ヘッダー | 各プレイヤーの得点・キャプテン・手札枚数。⚽がボールを持っている人 |
| 相手のベンチ | 相手が公開している選手の顔。伏せ札の枚数 |
| 場 | **種類ごとの山**（シュート／ドリブル／ディフェンス／キャッチ／選手）。山をクリックすると中身が全部見えます。右に山札と自分のコイン |
| 自分のベンチ | 自分の選手（公開）。いちばん左がキャプテン |
| 手札 | 自分の必殺カード（伏せ札） |

**場を種類ごとに重ねているのは、ルールブック9章の「場が大きくなってきたら種類ごとに分けて並べる」をそのままやっているからです。** 実際のプレイでは場に平均39枚、多いときは150枚以上たまります。

## 遊びかた（操作）

**カードを直接さわります。**

- **黄色く光って「撃てる」「奪える」「引き抜ける」と出ているカード** … いますぐできること
- **ふつうの見た目のカード** … 場に出して1枚引くことはできる
- **沈んで暗いカード** … 相手の番。いまは何もできない

カードを**クリック**すると持ち上がり、そのカードの上にボタンが出ます。
カードを**上へドラッグ**して相手に投げつけたり、場に放り込んだりもできます。

シュートを選んだら、狙う相手をクリックします。

演出の途中で画面をクリックすると、その演出を飛ばせます。

---

## 数値を変える

右上の「設定」からいつでも開けます（試合はやり直しになります）。

「**演出の速さ**」を「なし」にすると、アニメーションを飛ばして数値だけ確認できます。たくさん試したいときはこれが速いです。

---

## CPU同士で回す

設定画面の「**CPU同士で回す**」から、いまの数値のまま何百試合でも回せます。

見どころ：

- **3点に到達して決着した割合** … 低いと「点が入らないゲーム」になっています
- **連携技はどれだけ撃たれたか** … 2人技・3人技が撃たれないなら、揃える苦労に見合っていません
- **リアクションは報われているか** … キャッチ・ドリブルの成功回数と、連続で守り切った回数
- **イナズマコイン** … 増えすぎ（余る）／減りすぎ（技を撃ち直せない）を見ます
- **0-0で終わった試合** … 多いと守りが強すぎます
- **一度もボールに触らなかった人** … 多いと、一部の人だけで試合が進んでいます
- **【貫通】は効きすぎていないか** … 貫通と通常の決定率の差を見ます
- **円堂4種の勝率** … 4枚のキャプテンの強さが揃っているか
- **炎の風見鶏が手札に戻った回数** … 強すぎないかの目安

オレンジの数字は「そこが怪しい」という印です。**どうするかは作者が決めてください。**

## ファイルの中身

さわらなくて大丈夫ですが、**顔の見え方だけは調整しやすくしてあります。**

| ファイル | 役割 |
|---|---|
| `index.html` | 画面のかたち |
| `あそびかた.html` | 遊ぶ人向けルールブック（A4に印刷もできます） |
| `css/` | 見た目 |
| `js/config.js` | **画像の置き場所と、数値の初期値。まとめてここにあります** |
| `js/data.js` | カードの定義。**顔の拡大率・位置もここ** |
| `js/engine.js` | ルール。ルールブックv0.1のとおりに動きます |
| `js/ai.js` | CPUの考え方 |
| `js/sim.js` | CPU一括対戦の集計 |
| `js/render.js` `js/fx.js` `js/ui.js` | カードの絵・演出・操作 |
| `資料/` | 開発用のルールブック・効果設計メモ・仕事量リスト |
| `旧版/` | 前のバージョン（参考用） |

### 顔の大きさがずれたとき

キャラクター画像を差し替えて顔の位置がずれたら、`js/data.js` のそのキャラの行に次を足してください。

```
face: { zoom: 125, x: 50, y: 0 }
```

- `zoom` … 大きいほど顔が大きく写る（既定 125）
- `x` … 左右の位置（％。小さいと左寄り）
- `y` … 上下の位置（％。小さいと上寄り）

画像そのものは加工していないので、元ファイルはいつでも差し替えられます。

### 画像の置き場所を変えるとき

`js/config.js` の `assetBase` を書き換えてください。ここ1か所だけで済みます。

## 画像について

画像は `キャラクターメイン/` と `必殺技◯◯/` のファイルをそのまま読んでいます。base64での埋め込みはしていません。

- キャラクター … 256×256 の正方形（鬼道（雷門）のみ 1024×1024）
- 必殺技 … 1919×約1020 の横長。カードの形をこの比率に合わせているので、**絵は一切切れずに全部見えます**
