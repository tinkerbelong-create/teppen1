# テッペンとリーヨ！ ── テストプレイ環境

紙のカードゲーム「テッペンとリーヨ！」を、画面の上で試すための道具です。
最終的に作るのは紙のゲームです。これはその**調整用の道具**です。

**遊ぶ：** https://tinkerbelong-create.github.io/teppen1/

スマホでURLを開いて、ホーム画面に追加すればアプリのように使えます。

---

## 何ができるか

- **1人でCPUと対戦**（2〜4人。CPUは1〜3体）
- **CPU同士を高速で回して統計を取る**（バランス調整用）
- **数値を画面から変える**：初期手札／勝利点／コイン枚数／必殺カードの複製数／キャラカードの複製数／人数

数値を変えて何度も試し、紙にするときの枚数を決めるのが目的です。

---

## 遊び方（画面の見方）

| 場所 | 中身 |
|---|---|
| 上のバー | 各プレイヤーの得点・キャプテン・手札枚数。●がボールを持っている人 |
| その下 | 相手のベンチ。表向きのキャラクターカードが見える |
| まん中 | **場**。使ったカードが落ちる。コイン1枚で拾える |
| その下 | 自分の選手（公開） |
| 下のバー | 自分の伏せ札（必殺カード・コイン・ボール） |

**カードを直接さわって遊びます。**

- **黄色く光って「撃てる」と出ているカード** … いますぐワザが撃てる／拾える／引き抜ける
- **ふつうのカード** … 場に出して1枚引くことはできる
- **沈んで暗いカード** … 相手の番。いまは何もできない

カードを**タップ**すると持ち上がって、そのカードの上に操作ボタンが出ます。
カードを**上へドラッグ**して場に放り込む／相手に投げつけることもできます。

シュートを選んだら、狙う相手をタップします。

演出の途中で画面をタップすると、その演出を飛ばせます。

---

## 数値を変える

右上の「設定」からいつでも開けます（試合はやり直しになります）。

「**演出の速さ**」を「なし」にすると、アニメーションを飛ばして数値だけ確認できます。
たくさん試したいときはこれが速いです。

---

## CPU同士で回す

設定画面の「**CPU同士で回す**」から、いまの数値のまま何百試合でも回せます。

出てくる表の見どころ：

- **3点に到達して決着した割合** … 低いと「点が入らないゲーム」になっています
- **0-0で終わった試合** … 多いと守りが強すぎます
- **ボールに一度も触らなかった人** … 多いと、一部の人だけで試合が進んでいます
- **【貫通】は効きすぎていないか** … 貫通シュートと通常シュートの決定率の差を見ます
- **円堂4種の勝率** … 4枚のキャプテンの強さが揃っているか
- **炎の風見鶏が手札に戻った回数** … 強すぎないかの目安

赤い数字は「そこが怪しい」という印です。**どうするかは作者が決めてください。**

## ファイルの中身（さわらなくて大丈夫です）

| ファイル | 役割 |
|---|---|
| `index.html` | 画面のかたち |
| `css/` | 見た目 |
| `js/data.js` | カードの定義（画像はファイル参照。埋め込んでいません） |
| `js/engine.js` | ルール。ルールブックv0.1の通りに動きます |
| `js/ai.js` | CPUの考え方 |
| `js/sim.js` | CPU一括対戦の集計 |
| `js/render.js` `js/fx.js` `js/ui.js` | カードの絵・演出・操作 |
| `資料/` | ルールブック・効果設計メモ・仕事量リスト |
| `旧版/` | 前のバージョン（参考用に置いてあります） |

画像は `キャラクターメイン/` と `必殺技◯◯/` のファイルをそのまま読んでいます。
画像を差し替えたら、ファイル名を変えなければそのまま反映されます。
